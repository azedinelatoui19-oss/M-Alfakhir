# 🎁 نظام السحب على الخصومات

نظام حديث وآمن للسحب على الخصومات مع Google Sheets و Google Apps Script.

## 🚀 المميزات

- ✅ واجهة مستخدم جميلة وسريعة
- 🔒 نظام أمان متقدم (هاتف واحد مرة واحدة)
- 📊 تخزين آمن في Google Sheets
- ⚡ استجابة فورية
- 📱 متوافق 100% مع الموبايل
- 🌐 مجاني تماماً

## 🔧 الإعداد

### المتطلبات:
- Google Account (مجاني)
- GitHub Account (مجاني)

### الخطوات:

1. **Google Sheets:**
   - إنشاء ورقة عمل جديدة
   - التأكد من اسمها: `Sheet1`

2. **Google Apps Script:**
   - الذهاب إلى Google Apps Script
   - نسخ كود Backend
   - نشر كـ Web App

3. **GitHub Pages:**
   - نسخ الملفات (HTML, CSS, JS)
   - رفع إلى GitHub
   - تفعيل Pages من الإعدادات
